      eForms SDK Explorer

      Explore and compare different versions of the eForms SDK.

      The eForms SDK Explorer is a web application that allows you to explore the contents as well as changes between any two versions of the eForms SDK. The application is being developed by the Publications Office of the EU and is available as open source on GitHub. We welcome your feedback, suggestions for improvement as well as your contributions to the project.

      New to the SDK Explorer?

      The quick tour shows where to choose the versions, how to switch between sections and how changes are marked.

      Reading the comparison

      Select the base version, the one you are migrating from, and the target version, the one you are migrating to. Every tab then shows what changed between the two.

      • Added: exists only in the target version.
      • Removed: exists only in the base version.
      • Modified: exists in both versions, with differences.
